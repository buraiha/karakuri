# Karakuri

Karakuriは、日常の小さな不便を解消するアプリをひとつにまとめたWebアプリです。Googleアカウントでログインし、利用を許可されたアプリを選んで使います。

最初に作るのは、**iPhoneで音声入力した文章を、PCのブラウザへ送ってコピーできるアプリ**です。この機能から使い始め、実際の利用で価値を確かめながら、必要なアプリを追加していきます。

## 最初に実現したいこと

iPhoneの音声入力で文章を作り、その文章をPC上の作業で使えるようにします。

1. iPhoneで文章を入力する。音声入力を活用し、必要に応じて手で修正する。
2. 内容を確認し、送信ボタンを押す。
3. 別のPCで開いている受信画面に、送信した文章が自動で表示される。
4. PCで文章をコピーし、使いたいアプリへ貼り付ける。

送信を確定した文章を連携する仕組みです。入力途中の文字や音声を逐次配信する機能ではありません。文章連携アプリの正式名称は未定です。

## 利用の流れ

```text
Googleアカウントでログイン
  → 初回は利用申請・管理者による承認
  → アプリ選択画面
  → 利用を許可されたアプリを開く
```

Google認証とKarakuriの利用承認、各アプリの利用権限を分けて管理します。ログインできても、承認待ち・拒否の場合はアプリを利用できません。承認後も、利用できるのは個別に権限が付与されたアプリだけです。

## 管理者ができること

管理画面で、利用者とアプリごとの利用状態を管理します。

- 利用申請を確認し、承認・拒否する。
- 利用者ごとに、各アプリの利用を許可・取り消しする。
- ユーザーとアプリの組み合わせごとに課金状態を管理し、利用可否へ反映する。

利用者・アプリ・承認状態・利用権限・課金状態はデータベースに保存します。管理操作は管理者に限定し、アプリの利用可否は画面だけでなくサーバー側でも検証します。

料金、課金とみなす時点、有効期間、無料利用の扱いは未定です。決済サービスとの連携や自動請求は初期開発の対象に含めません。

## 現在の開発状況

Python＋Djangoを採用し、Google認証・利用申請・管理者による承認・アプリ別権限・課金状態管理の基盤を実装しています。画面はDjango Templates、管理画面はDjango Admin、DBはSQLiteで運用を始め、設定でPostgreSQL・MySQLへ切り替えられます。

ログインはGoogle認証に限定します。ログイン状態は成立から14日固定で、利用による期限延長は行いません。課金状態と利用許可は別項目として管理します。

認証・権限の自動テストに加え、開発用Google登録・実アカウントでのログイン・初期管理者設定・管理画面からの利用許可を確認済みです。文章の送受信機能は未実装で、許可されたアプリの入口まで用意しています。iPhone・Windows PCでの実機動作、ホスティング・本番運用構成は未検証・未確定です。

セットアップ・起動・テスト・Google登録の手順は [開発ガイド](docs/development.md) を参照してください。
